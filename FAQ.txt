Frequently Asked Questions (FAQs)

Q: How do I install PHPMake?
A: Install via Composer:
composer require --dev phpmake/phpmake

Q: How do I create a sample build.json?
A:
php vendor/bin/phpmake --init

Q: What is the basic structure of `build.json`?
A:
{
  "name": "Project Name",
  "description": "Project description.",
  "version": "2.0.1",
  "targets": {
    "target_name": {
      "depends": ["dependency1", "dependency2"],
      "tasks": [
        {"type": "task_type", "params": { ... }}
      ]
    }
  },
  "default_target": "default_target_name"
}

Q: How do I run a specific target?
A: Use the target name as an argument:
phpmake <target_name>

Q: What tasks are supported?
A:
- `create_directory`: Create directories (`name`)
- `delete`: Remove files/directories (`path`)
- `copy`: Copy files/directories (`source`, `dest`)
- `exec`: Execute shell commands (`command`)
- `echo`: Output messages (`message`)
- `archive`: Archive/compress a file or directory (`source`, `output`)

Q: Are paths outside the project allowed?
A: No. Filesystem tasks (`create_directory`, `delete`, `copy`, `archive`) only accept paths that resolve inside the current working directory. Attempts to use `..` or absolute paths outside the project are rejected as a safety violation.

Q: How do I enable debug/verbose logging?
A: Add the `--debug` flag:
phpmake --debug

Q: How do I validate my build.json?
A:
phpmake --validate-build

Q: What does the `--diagnostics` flag do?
A: Shows system info like PHP version, OS, and loaded extensions.

Q: How do I handle circular dependencies?
A: The tool detects cycles and throws an error.

Q: Does this work on Microsoft Windows?
A: Yes.

Q: How do I create a custom task?
A:
1. Create a new class in `src/Task/Types` extending `BaseTask`.
2. Implement `runTask()`, `validateParams()`, and `getType()`.
3. Update `TaskFactory` to map the new task type.

Q: Where are logs stored?
A: By default, logs are in the project's root in `build.log`, unless `--no-log` is used. Logs rotate at 10MB and keep up to 5 rotated files.

Q: Why does the build stop abruptly?
A: The tool stops on the first failed task by default. Use `--debug` for detailed error info.

Q: Can I use PHPMake in CI/CD pipelines?
A: Yes, it's designed to work with any environment supporting PHP.
