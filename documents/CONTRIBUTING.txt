# Contributing

Bug reports, tests, documentation, maintenance, and focused features are welcome.

## Bug reports

Include the PHPMake version, PHP version, OS, extensions, minimal build file, reproduction steps, and sanitized output. Never include secrets. Report vulnerabilities privately using [SECURITY.md](../SECURITY.md).

## Development

Requirements: PHP 8.0+, Composer 2+, and `ctype`, `json`, `zip`.

```sh
composer install
composer test
composer lint
composer analyse
composer format-check
composer refactor-check
```

CI tests PHP 8.0–8.5 on Linux and Windows. Preserve PHP 8.0 compatibility and both supported operating systems.

## Tests and changes

- Use PHPUnit and Arrange / Act / Assert.
- Do not add mocks or mocking frameworks.
- Cover success, failure, boundaries, and platform behavior.
- Keep tests deterministic, isolated, and time-bounded.
- Avoid new dependencies unless necessary.
- Update the schema and user-facing docs when configuration behavior changes.
- Never commit dependencies, credentials, local configuration, or generated reports.

The Xdebug coverage job enforces [the coverage policy](CODE-COVERAGE.md). Use the successful CI artifact for current coverage figures.

## Pull requests

Explain the problem, behavior change, compatibility impact, and tests actually run. Keep changes focused. Do not claim CI passed until GitHub Actions confirms it.

## Architecture

Task metadata belongs in `TaskDefinitionRegistry`; the public build-file contract belongs in `schema/build-schema.json`. See [User Guide](USER-GUIDE.md) and [Architecture](ARCHITECTURE.md).
