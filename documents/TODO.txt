* Add a dedicated case-sensitive APFS test volume to macOS CI; current tests only exercise case-only siblings when the runner filesystem supports them.
* Add CI coverage for the POSIX process-group fallback on a host without the POSIX extension; it requires both `setsid` and `kill` executables, otherwise only the direct process can be terminated.
* Evaluate Windows Job Object support for reliable descendant cleanup; `taskkill /T` and the WMI parent-chain fallback cannot guarantee cleanup when an intermediate process exits before cleanup or a descendant detaches.
* Document and test that POSIX descendants which deliberately create a new session escape PHPMake's original process group.
* Define Windows host-cancellation behavior; cooperative SIGINT/SIGTERM cancellation is currently supported only on POSIX CLI runtimes with `pcntl`.
